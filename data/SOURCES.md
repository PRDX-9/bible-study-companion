# Strong's Dictionary Data Source

The files `strongs-hebrew.json` and `strongs-greek.json` are derived from Open Scriptures Strong's dictionaries:

https://github.com/openscriptures/strongs

Source files used:

- `hebrew/strongs-hebrew-dictionary.js`, blob `b5b7cd2799981b0bcf96a93541236187b2c85fcf`
- `greek/strongs-greek-dictionary.js`, blob `0bebdeeec31f93b42ec591909da3f18626a684a8`

The source headers identify the underlying dictionaries as James Strong's 1890 and 1894 works. The Open Scriptures JSON conversion is marked CC BY-SA and says it was derived from public domain XML and source material. This app keeps the data on-device and uses it only for lookup.
